👋 欢迎使用 QQ 空间导出助手

把 QQ 空间的说说、日志、相册、好友等内容备份为本地文件

1

打开并登录 QQ 空间

浏览器打开 user.qzone.qq.com 并登录。备份别人的空间就打开对方主页（能正常浏览即有权限）。

2

自动弹出备份窗口

打开 QQ 空间页面后，助手会自动弹出「一键备份」窗口，无需手动点击扩展图标。

3

选择内容，开始备份

在弹窗中勾选要备份的模块，确认后点「开始备份」。期间保持空间页面不关闭、不刷新。

文案 文案内容

  • 包含：说说文字、日志正文、留言、好友列表、分享记录等文本数据
  • 格式：HTML（浏览器直接看，默认）/ MarkDown（笔记工具）；JSON 始终自动导出，好友额外导出 Excel
  • 存储：Chrome / Edge 直接写入你选择的目录；Firefox 自动写入浏览器下载目录的 QQ空间备份_/ 文件夹（不再打包 ZIP）
  • 特点：采集即得到，不依赖额外下载

媒体 媒体文件

  • 包含：说说配图、日志插图、相册相片、视频、头像等文件
  • 处理：文案里只记录 URL 引用，需额外下载才能得到本地文件
  • 下载方式：助手直写目录（一步到位）/ 浏览器下载器 / Aria2协议下载器
  • 注意：外部下载器的文件落在它自己的目录，需自行合并回备份目录
范围 备份范围
全部数据

完整备份所有内容。适合首次备份，或想重新开始一次完整备份的场景。

上次之后

仅采集上次备份后新增的内容。需保留上次备份文件并与本次产物合并，否则备份不完整。

指定时间

采集某个时间点之后发布的内容。适合只想要某段时期的数据，或补备某个时间段的遗漏。

各模块独立配置，在助手「设置」页对应模块的「备份范围」选项中调整。非全量模式下，上次备份文件必须保留。

默认配置组合
文案格式HTML
备份范围全量备份
媒体下载助手直写目录（Firefox 为「浏览器下载器」）

首次使用建议采用默认组合，配置简单、上手快速。日常增量备份（只采集上次之后的新内容）可在「设置」页对应模块的「备份范围」中调整。

兼容 浏览器差异
· Chrome / Edge：文案写入「你选择的目录」；支持「助手直写目录」（默认），媒体与文案同目录、一步到位。
· Firefox：不支持「助手直写目录」，文案自动写入「下载目录 / QQ空间备份_<uin>/」文件夹，默认用「浏览器下载器」。
· 无论哪个浏览器，改用外部下载器（浏览器下载器 / Aria2）时，媒体落在它自己的目录，需自行合并回备份目录。
提示：文案格式选 HTML 时，备份完成后打开备份目录里的 index 文件即可离线浏览全部内容； 选 MarkDown 时需用对应的笔记工具打开。JSON 格式始终自动导出，更多选项可在助手「设置」页调整。
若选用「浏览器下载器」下载媒体，请提前关闭浏览器「下载前询问每个文件的保存位置」，否则每个文件都需手动确认； 浏览器之间在保存位置 / 下载方式上的差异与合并说明，见上方「浏览器差异」。
